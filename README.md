# A collection of data-driven projects

Focused on data extraction, API integration, and business intelligence visualization.

# 📁 Repository Structure (Click to access) :


## 🌐 Public Repositories :

- [**`Power BI Analytics/`**](https://drive.google.com/drive/folders/1uxglF8IGByrR6Kkb10hUplz6JEJ2O0WI?usp=sharing)
* End-to-end business intelligence projects implementing star schema modeling alongside automated data cleaning pipelines in Python and Power Query.

- [**`Vibe-coding-Analyse/`**](https://drive.google.com/drive/folders/1I_sor6fww2rYq9Bff2mh5TBKl8Zy_RUk?usp=sharing)
* Secure customer churn analysis workflow orchestrated via Claude Code. Engineered with strict guardrails: isolated from external services and restricted to read-only database access (zero write/execute permissions).

- [**`Web_Scraping/`**](https://drive.google.com/drive/folders/16ln-rImsqqMSzUiQ4nKW_IOkgesJq5n7?usp=sharing)
* Multi-source web scraping pipelines engineered to extract, structure, and analyze raw data across diverse online platforms.

- [WildFlix, Movie Recommendation](https://wildflix-data-app.streamlit.app/)
* An end-to-end movie recommendation engine with interactive filtering and business analytics : TMDB API data, cleaning with pandas, TF-IDF and cosine similarity, deployed as a multilingual Streamlit app.

- [Toys and Models, Executive Dashboard](https://drive.google.com/drive/folders/1xPfRDjTGJdZ2du3sL-_a7A6fpXC9lngQ)
* A daily-refreshed Power BI executive dashboard for a scale-model retailer : EDA on a relational database, 19 KPIs across HR, sales, finance and supply chain, built with SQL, Python and DAX.

## 🔒 Private Repositories :

- [**`Smart_Real_Estate/`**](https://smart-real-estate-seven.vercel.app/en)
* Automated real estate intelligence pipeline that scrapes multiple sources to aggregate market pricing and generate real-time analytics for the Cyprus property market (Auto-updates every 2 days).

- [**`supermarket-tracker/`**](https://supermarket-tracker.thibaud-derville.workers.dev/en/)
* Multi-source web scraping tool that tracks and compares food prices across major supermarkets (Auto-updates on the 5th, 12th, and 20th of each month).
